# API-контракт user-service, версия 1

Дата фиксации: 18.11.2026. HTTP JSON, UTF-8; время UTC ISO 8601.

| Метод | Путь | Назначение | Коды |
|---|---|---|---|
| POST | /users | Создать пользователя | 201, 400 |
| GET | /users | Список пользователей | 200 |
| GET | /users/{user_id} | Получить пользователя | 200, 400, 404 |
| PUT | /users/{user_id} | Полностью заменить email/name | 200, 400, 404 |
| DELETE | /users/{user_id} | Удалить пользователя | 204, 400, 404 |
| GET | /health | Проверить локальную живость и БД | 200 |

User: {"id":1,"email":"ivan@example.com","name":"Иван","created_at":"2026-11-18T10:00:00Z"}.
POST/PUT: {"email":"ivan@example.com","name":"Иван"}. Email валидируется, приводится к нижнему регистру и уникален; имя 1–100 символов после strip. Лишние поля, неверный JSON и невалидные параметры → 400. Отсутствующий ID → 404. DELETE 204 без тела. Ошибка: {"error":"описание"}. Пагинация и авторизация не входят в учебный контракт. Удаление пользователя не удаляет старые заказы: сервисы владеют разными БД.

OpenAPI: /openapi.json; Swagger: /docs. /metrics/ — экспорт Prometheus. Gateway: /api/users, /docs/users/docs.
